# AI Paper Daily 🧠

> 每天追踪 AI 领域最新论文（Agent、推理、多模态、训练、安全等），精选 1-2 篇最有价值的进行深度解读。

## 为什么做这个

arXiv 日均 500+ 篇 AI 相关论文，但中文世界缺少高质量、有观点的深度解读——大部分要么是机器翻译摘要，要么是泛 AI 新闻聚合。

这个项目的目标是：**用跨域视角（AI + Web3 + 创业实战），把最有价值的论文讲清楚、讲出观点**。

## 覆盖主题

- 🤖 AI Agent / Multi-Agent / Agentic Systems
- 🧠 LLM 推理 / 规划 / 对齐
- 🎨 多模态 / 视觉语言模型
- 🔐 AI 安全 / 可靠性 / 评估
- 🏗️ AI 基础设施 / 训练 / 推理优化
- 🔗 AI + Web3 / 去中心化 AI
- 💡 Prompt Engineering / AI Native 应用

## 内容结构

```
papers/       → 论文 PDF 原文（arXiv 开放获取）
analyses/     → 深度分析文章（Markdown，中英双语）
```

每篇分析包含：
- 📌 一句话亮点
- 🎯 解决了什么问题
- 🔬 方法概要
- 📊 关键结果
- 💡 为什么值得关注（跨域视角点评）
